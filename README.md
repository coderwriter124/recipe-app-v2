# Recipe App v2

Cute full-stack recipe app with search, cuisine/category filters, clickable recipe details, Google recipe links, favorites, extra starter recipes, and a free local AI-style recommendation assistant.

## Run on Windows

```cmd
cd /d C:\Users\priya\recipe-app-v2
npm install
npm run dev
```

Open http://localhost:5173. The recommendation assistant matches the included catalog locally and requires no API key or paid AI service.
